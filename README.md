# Forest Cover Type Prediction

A supervised machine-learning project that classifies forest areas into one of seven cover types using cartographic and environmental features.

## Objective
Explore the dataset, prepare the features, compare classification algorithms, and identify a strong model for predicting forest cover type.

## Workflow
- Inspect the dataset and perform exploratory data analysis.
- Prepare features and apply scaling where appropriate.
- Train and compare six classification algorithms.
- Tune and evaluate a Random Forest classifier.

## Model and result
The notebook reports **86.9% accuracy** for the tuned Random Forest model under its evaluation setup. Results may vary on new or geographically different data.
